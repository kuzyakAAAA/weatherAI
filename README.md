# 👕 Weather Outfit Assistant — Telegram бот

Telegram-бот, который помогает подобрать одежду по погоде с использованием AI (Mistral AI).  
Пользователь указывает город и дату, бот получает прогноз погоды и генерирует персонализированную рекомендацию с учётом выбранного стиля (casual / business / sport).

## ✨ Возможности

- 📍 Погода на сегодня или на любой день в пределах 5 дней
- 🤖 AI-рекомендации на основе Mistral AI (прямые HTTP-запросы, без сторонних библиотек)
- 👔 Выбор стиля одежды: casual, business, sport
- 💾 История запросов и сохранение настроек пользователя в **PostgreSQL**
- 🔄 Смена стиля в любой момент командой `/style`
- 🌐 Поддержка городов на английском языке (например, Moscow, London)
- 🧠 Fallback‑советы при недоступности AI
- ❌ Команда `/cancel` для сброса диалога

## 🏗 Архитектура проекта

Проект построен по модульному принципу с асинхронными клиентами:

- **API Client** — получение текущей погоды и 5‑дневного прогноза от OpenWeatherMap.
- **AI Client** — генерация советов через Mistral AI (прямые HTTP‑запросы, `aiohttp`).
- **DB** — асинхронное хранилище PostgreSQL (таблицы `users` и `history`).
- **UI** — Telegram‑бот с интерактивными кнопками и управлением состояниями.

Компоненты связаны через **Orchestrator**, который управляет потоком данных и обработкой ошибок.

## 🛠 Технологии

- Python 3.14+
- `python-telegram-bot` (v20+) — асинхронный фреймворк для бота
- `aiohttp` — асинхронные HTTP‑запросы к API погоды и Mistral
- `asyncpg` — асинхронный драйвер PostgreSQL
- PostgreSQL — основная база данных
- OpenWeatherMap API — погода
- Mistral AI API — генерация текстов (бесплатный тариф `mistral-tiny`)
